# GovAssist – Voice-Powered Government Assistant

GovAssist is a voice-enabled AI assistant designed to help users explore government schemes and access relevant public-service information in **Telugu, English, and Hindi**. It provides a simple interface for asking questions, exploring scheme categories, and accessing official application websites.

## 🚀 Features

- **Multilingual Voice Assistant:** Interact with GovAssist using Telugu, English, or Hindi.
- **Voice and Text Interaction:** Ask questions through the microphone or by typing.
- **Speech Support:** Uses speech recognition and text-to-speech capabilities to support conversational interactions.
- **Government Scheme Explorer:** Browse a starter catalogue of government schemes by category.
- **PDF Upload:** Upload government scheme PDF documents for backend storage.
- **AI-Powered Responses:** Designed to support conversational question answering about government schemes.
- **Simple User Interface:** Clean, accessible interface for exploring public-service information.
- **Official Website Guidance:** Encourages users to verify scheme eligibility and application details on official government portals.

## 🛠️ Technology Stack

- **Python**
- **Lyzr AI**
- **Retrieval-Augmented Generation (RAG)**
- **Vosk** – Speech recognition
- **Pydantic** – Structured data validation
- **Speech-to-Text and Text-to-Speech**
- **HTML, CSS, and JavaScript** – Web interface, if used in the implementation

## 🖥️ Application Sections

### 1. Voice Assistant
Choose a preferred language, speak through the microphone, or type a question to interact with GovAssist.

### 2. Explore Schemes
Browse the available starter catalogue and filter schemes by category.

### 3. PDF Upload
Upload a government scheme PDF for backend storage. In the current interface, PDF text extraction and document-based question answering are not yet enabled.

## 🎯 Project Objective

The goal of GovAssist is to make government scheme information easier to explore through multilingual voice and text interactions, helping users find relevant information and official application resources.

## ⚠️ Important Note

GovAssist is an informational assistant. Scheme availability, eligibility criteria, required documents, benefits, and application procedures may change. Always verify the latest information through official government websites before applying.

## 🔒 Security

- Keep API keys and credentials in environment variables.
- Do not commit `.env` files or other secrets to GitHub.
- Use a `.env.example` file containing placeholder values when documenting required environment variables.
- Avoid uploading sensitive personal documents.
